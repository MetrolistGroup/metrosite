This is a reference for all content styles available on Metrosite. Use it when writing blog posts or documentation.

---

## Headings

# Heading 1: Page titles
## Heading 2: Section titles
### Heading 3: Subsections

Headings use the M3 type scale with primary color for H1 and H2.

---

## Text Formatting

**Bold** for emphasis. *Italic* for subtle emphasis. `Inline code` for references to variables, commands, or paths.

Links are underlined with the primary color:

[Metrolist on GitHub](https://github.com/MetrolistGroup/Metrolist)

## Blockquotes

> Use blockquotes for callouts or highlighted text. They have a primary-colored left border and subtle background.
>
> Multiple paragraphs work inside blockquotes.

## Alerts

Alerts are custom HTML blocks for important notices. Three types:

<div class="alert alert-tip">
  <div class="alert-header">
    <span class="material-symbols-rounded">lightbulb</span>
    <span class="label-l">Tip</span>
  </div>
  <div class="alert-content">
    Tips for best practices and helpful suggestions. Green accent.
  </div>
</div>

<div class="alert alert-important">
  <div class="alert-header">
    <span class="material-symbols-rounded">priority_high</span>
    <span class="label-l">Important</span>
  </div>
  <div class="alert-content">
    Critical information users need to know. Primary color accent.
  </div>
</div>

<div class="alert alert-warning">
  <div class="alert-header">
    <span class="material-symbols-rounded">warning</span>
    <span class="label-l">Warning</span>
  </div>
  <div class="alert-content">
    Warnings about potential issues or limitations. Yellow accent.
  </div>
</div>

## Code

### Inline

Use backticks for `inline code` like variables or file paths.

### Blocks

Code blocks have a dark background and monospace font:

```kotlin
// Material You color generation
fun generateTonalPalette(sourceColor: Int): TonalPalette {
    val hct = Hct.fromInt(sourceColor)
    return TonalPalette.of(hct.hue, hct.chroma)
}
```

```css
/* CSS custom properties */
:root {
  --md-sys-color-surface: #0F0F0F;
  --md-sys-color-on-surface: #E6E6E6;
}
```

```bash
# Build commands
npm run build
npm run preview
```
