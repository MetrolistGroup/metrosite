Follow these steps to get Metrolist up and running.

1. Download the latest APK from the [Download](/download) page.
2. Open the APK on your device.
3. If prompted, enable `Install from Unknown Sources`.
4. Tap Install.

> **Note**: Metrolist is currently in alpha. You might encounter bugs or incomplete features.

### Advanced Setup
If you want to verify the build, you can check the MD5 hash:
```bash
md5sum metrolist-v1.0.apk
```

### First Run
When you first open Metrolist, you'll be greeted with a clean interface that dynamically adapts to your device's wallpaper and theme. You can start searching for music immediately.
